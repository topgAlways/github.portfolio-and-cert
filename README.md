# Mastercard Cybersecurity Virtual Experience 

#About This Project

I completed the Mastercard Cybersecurity Virtual Experience on Forage to get hands-on
practice with security awareness and social engineering defense. In this simulation, I
stepped into the role of an analyst on Mastercard's Security Awareness Team. My job was to
design a realistic phishing test for employees and figure out how to train the teams that fell for it

*What i learned
A good phishing email test need to be balance  If a test email is too fake, you learn nothing. If
it's too sneaky without clear clues, employees just feel tricked instead of learning
what to look for.
Training has to match the job: A finance worker and a software engineer face
different kinds of fake emails. Security advice works much better when it fits a team's
daily routine.
Data tells the story: Seeing the click rates side-by-side made it much easier to
